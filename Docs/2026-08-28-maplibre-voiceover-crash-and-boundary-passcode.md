# 2026-08-28 — MapLibre VoiceOver crash fix & boundary/passcode work

## MapLibre 6.18.0 → 6.18.0-patch0 (VoiceOver map crash)

### Problem
Crashlytics issue `8a3647f99fc8a4a47c8174d15810f0b7`: `std::out_of_range` thrown from
`-[MLNMapView accessibilityElementForAnnotationWithTag:]` while VoiceOver enumerates map
annotations. Upstream: maplibre/maplibre-native#3923, fixed by PR #3926 (bounds check before
the annotation-tag lookup).

### How the patch tag resolves
The distribution repo (`maplibre/maplibre-gl-native-distribution`) publishes the backport as the
semver **prerelease** tag `6.18.0-patch0` (release published 2025-11-07, i.e. *after* 6.18.0 and
6.18.1 — it is a backport onto the 6.18.0 line, not a pre-6.18.0 build). Release notes contain a
single entry: "dd accessibility annotation check (#3926)".

Because SPM orders `6.18.0-patch0` **below** `6.18.0`, the existing
`upToNextMajorVersion(6.0.0)` range would never select it (ranges exclude prereleases). So the
package reference was changed to an **exact version** pin:

```
D9592D502858560B00C90542 /* XCRemoteSwiftPackageReference "maplibre-gl-native-distribution" */ = {
	isa = XCRemoteSwiftPackageReference;
	repositoryURL = "https://github.com/maplibre/maplibre-gl-native-distribution";
	requirement = {
		kind = exactVersion;
		version = "6.18.0-patch0";
	};
};
```

Note: this pin must be revisited when moving to 6.19+/6.2x — an exact prerelease pin will not
float forward on its own.
